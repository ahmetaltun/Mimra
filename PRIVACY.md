# Privacy Policy

Mimra is built around a single foundational commitment: **your clipboard data is private, sensitive, and belongs solely on your device**.

---

## Core Privacy Principles

1. **100% On-Device Storage**  
   All saved clipboard history is stored strictly on your local disk in an embedded SQLite database located at `~/Library/Application Support/Mimra/mimra.db`. Data is never synchronized, uploaded, or mirrored to external cloud servers.

2. **Zero Telemetry and Zero Analytics**  
   Mimra contains no analytics SDKs, telemetry probes, tracking cookies, or user profiling tools. We do not track what you copy, how often you paste, or how you interact with the software.

3. **Zero External AI Processing**  
   Text recognition (OCR) performed on copied images runs entirely on your local machine using Apple's native Vision framework. Image payloads are never transmitted across the network for recognition or parsing.

4. **Network Activity Scope**  
   Mimra has no remote network dependency. The only outbound network connection made by the application occurs when checking for software updates via Sparkle (querying the cryptographically signed `appcast.xml` on GitHub Releases), which can be toggled or disabled in Settings.

---

## Automatic Filtering of Sensitive Data

Before any clipboard item is ingested into the persistent storage engine, Mimra inspects pasteboard metadata in memory using a strict privacy filter:

- **Password Managers**: Copies originating from known credential managers (such as 1Password, Bitwarden, KeePassXC, and macOS Keychain) are ignored and dropped immediately.
- **Concealed Markers**: Items marked with standard macOS confidential types (e.g., `org.nspasteboard.ConcealedType` and `org.nspasteboard.AutoGeneratedType`) are rejected before touching storage.
- **Transient Data**: Ephemeral data flagged with transient copy markers is excluded from history.

---

## User Privacy Controls

Mimra provides full manual control over clipboard retention and recording:

- **Pause Capture**: Instantly halt clipboard monitoring from the menu bar status icon.
- **Ignore Next Copy**: Temporarily bypass the next immediate copy event.
- **Application Blacklisting**: Add any installed application to the Ignore list in Settings to prevent Mimra from ever reading copies originating from that app.
- **Excluded Formats**: Disable specific data types (such as RTF, HTML, images, or file references) so they are never recorded.
- **Retention & Clearing**: Configure strict item limits, time-based retention pruning, or clear unpinned and complete history at any time.
