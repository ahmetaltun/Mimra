# Contributing to Mimra

Thank you for your interest in contributing to Mimra. We welcome improvements, bug reports, and optimizations that align with our core commitment to security, privacy, and native Apple Silicon performance.

For security vulnerabilities, please consult our [Security Policy](SECURITY.md) to report issues privately.

---

## 1. Core Operating Principles

Before writing code, please review the non-negotiable architectural boundaries outlined in [AGENTS.md](AGENTS.md):

1. **Security & Privacy First**:
   - `security/privacy > data correctness > reliable paste > keyboard accessibility > performance > feature completeness > visual decoration`.
   - Never log raw clipboard contents, preview snippets, OCR text, file paths, or private parameters.
   - Secret markers (`org.nspasteboard.ConcealedType`, `org.nspasteboard.AutoGeneratedType`, password manager bundle IDs) must be filtered in Swift **before** reaching Rust, SQLite, or disk.

2. **Strict Component Boundaries**:
   - **SwiftUI / AppKit**: Controls UI, `NSPanel`, `NSStatusItem`, event interception, hotkeys, and Accessibility paste. Never writes raw SQL or directly accesses SQLite.
   - **Rust (`RustCore`)**: Owns the SQLite database, FTS5 index, deduplication, normalization, retention cleanup, and search ranking. Must never interact with AppKit/UIKit APIs.
   - **UniFFI Bridge**: Synchronous C-ABI layer. Must be called exclusively from off-main background workers or actors in Swift—**never block the main actor on Rust calls**.

## 2. Development Prerequisites

Contributions require an Apple Silicon Mac running macOS 15.0 or later:

- **Hardware**: Apple Silicon (`arm64`, M1 or newer). Intel hardware is unsupported.
- **Operating System**: macOS 15.0 (Sequoia) or later.
- **Xcode**: Xcode 16.0 or newer with Command Line Tools installed.
- **Rust**: Rust stable (1.80+) with the `aarch64-apple-darwin` target:
  ```sh
  rustup target add aarch64-apple-darwin
  ```

Validate your host setup using the environment script:
```sh
./scripts/check-env.sh
```

---

## 3. Building Mimra

Mimra uses modular build scripts located in `scripts/`:

1. **Compile Rust Core static library**:
   ```sh
   ./scripts/build-rust.sh debug
   ```

2. **Generate UniFFI Swift bindings**:
   ```sh
   ./scripts/generate-bindings.sh
   ```

3. **Build Mimra.app**:
   ```sh
   ./scripts/build-app.sh debug
   ```
   The compiled bundle will be staged at `build/Mimra.app`.

4. **Package Drag-to-Applications DMG**:
   ```sh
   ./scripts/build-dmg.sh
   ```

## 4. Running Tests & Quality Gates

Every contribution must pass the comprehensive automated verification test suite:

```sh
./scripts/test-all.sh
```

Individual checks can also be executed directly:

- **Rust Formatting**:
  ```sh
  cd RustCore && cargo fmt --all --check
  ```
- **Rust Clippy (Zero Warnings)**:
  ```sh
  cd RustCore && cargo clippy --all-targets -- -D warnings
  ```
- **Rust Unit & Property Tests**:
  ```sh
  cd RustCore && cargo test --all --locked
  ```
- **Swift 6 Strict Concurrency**: All Swift code must compile cleanly under `-strict-concurrency=complete`.

---

## 5. Pull Request Guidelines

1. **Atomic & Focused**: Keep PRs focused on a single feature, bug fix, or performance improvement.
2. **Test Coverage**: Accompany every functional change with negative and edge-case automated tests (empty content, invalid Unicode, multi-representation pasteboard items).
3. **Documentation Updates**:
   - If introducing an architectural decision or changing data schemas, record an entry in [docs/DECISIONS.md](docs/DECISIONS.md).
   - Update milestone progress in [docs/STATUS.md](docs/STATUS.md) when completing planned roadmap tasks.
